# CRM scoring agents

Static dashboard for [github.com/dsoosai/crm-scoring-agents](https://github.com/dsoosai/crm-scoring-agents).
It replays 15 months of lead scoring and 6 quarters of account scoring, with scripted drift,
and shows every agent decision. Regenerate with `crm-agent simulate`, then publish with `make space`.
